Minimal ABI fragments used by the additional Decimal operations.

Each JSON file records its public source and retrieval date. The source address
may be an implementation contract; runtime calls target configured proxies.
No deployment bytecode, credentials or node endpoints are included.

`legacy.json` is derived from pinned JS call signatures, not a currently verified
deployment. Those methods require explicit legacy opt-in. Current API metadata
and the node's bundled ABI files do not always match; do not replace these files
with all node ABIs indiscriminately.

See the bilingual transaction-parity-development guides and THIRD_PARTY_NOTICES.md.
