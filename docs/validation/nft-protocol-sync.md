## Sources And Semantics

The current NFTCenter proxy is 0x443cc8ac24630be9257483a09c34ffa81608eace.
getImpl() and implementation(kind,withReserve) were independently read:

- [NFTCenter implementation/ABI/source](https://api.decimalchain.com/api/v1/contracts/0xced55da70f42ab101b4ce10aa9e767607cef5146).
- [Reserved DRC721](https://api.decimalchain.com/api/v1/contracts/0xe0f7399e648a140d8242c98930ee3d0570d3738b).
- [Reserved DRC1155](https://api.decimalchain.com/api/v1/contracts/0x392165f3ad7b155dceb30e42d3d042212d6adc87).
- [Reserveless DRC721](https://api.decimalchain.com/api/v1/contracts/0x52eecb2f24464b7f221f403e194e0aa185ce2994).
- [Reserveless DRC1155](https://api.decimalchain.com/api/v1/contracts/0xc1d328429fd10d0dd9c8324a5d37fb9a1bdd966f).

Verified API responses supplied ABI JSON and base64 source. Sources were decoded
as text, never executed. Bundled subsets retain origin, implementation and source
SHA256. Creation takes creator/symbol/name/contractURI/refundable/burnable and only
deploys/registers a collection. Reserved creation and mint are separate calls.

ReserveType None=0, DEL=1, DRC20=2. MIN_RESERVE=1e15 RAW units. DRC1155 mint receives
TOTAL reserve and checks total/amountToMint against the minimum for a new ID.
Existing IDs require the same type and total=rate(id)*amountToMint. SDK additionally
checks the ERC20 address because the source does not compare it on additional mint.
The SDK rejects reserve data on a reserveless collection instead of silently ignoring it.

setTokenURI is absent from these four NFT ABIs. It remains a legacy-only opt-in
surface, excluded from the current canonical profile. NFT permit mint is not added
or claimed verified here. Approval, where needed, remains a separate explicit call.

## Console Contract

Use src/decimal_web3_sdk/profiles/candy_mainnet_v1.json generated by
scripts/generate_nft_profile.py. Its NFT sections come only from the bundled
nft_center/nft_721/nft_1155 ABI snapshots. Test tests/test_nft_protocol.py compares
Python builder calldata with this shared unsigned profile, validates exact reserve
rules and decodes the real creation receipt without inventing minted token IDs.

These are offline regressions plus read-only protocol evidence, not a funded
create/approve/mint/burn lifecycle. Console source is maintained separately and was
not modified here. No published version or production contract was changed.

Local verification: 31 new NFT tests, 360 tests passed in total. Ruff, reference
generation, NFT profile generation --check and secret audit passed. The audit
inspected 210 candidate source files and found no secrets. The existing upstream
websockets.legacy deprecation warning remains. No new wheel was published and no
commit was made. The older upstream comparison report describes the released
baseline, not proof of these unreleased corrections or new on-chain settlement.
