# Требования Для Установки
[Оглавление](README.md) | [English](../en/install.md) | [Релизы](releasing.md)

## Минимальные Требования
- CPython **3.10 или новее** и pip. Локально проверен Python 3.12, 64-битный.
- Интернет для загрузки SDK с GitHub и зависимостей из настроенного индекса Python-пакетов.
- Доступ по HTTPS к Decimal RPC для сетевых операций. Для локальной подписи и кодирования нода не нужна.
- Рекомендуется отдельное виртуальное окружение; права администратора/root не требуются.
- Git, Node.js, Go, Java, Android SDK, GPU и собственная блокчейн-нода не нужны.

Измеренного минимального объема RAM/диска нет. Небольшой wheel SDK не включает
загрузки зависимостей: pip устанавливает их отдельно. Потребление ресурсов зависит
от нагрузки, параллельных запросов, зависимостей и дополнительных инструментов.

## Операционные Системы
Wheel SDK имеет формат `py3-none-any`: сам пакет не содержит платформенного
исполняемого файла и не привязан к одной ОС.

| Платформа | Проверка / ограничения |
| --- | --- |
| Windows | Локально пройдены тесты и чистая установка pip на CPython 3.12, 64-битном. |
| Linux | CI настроен на Ubuntu с CPython 3.10, 3.12 и 3.13; успешность смотрите в результатах конкретного запуска. |
| macOS | Ожидается совместимость при наличии подходящих Python и wheel зависимостей; в этой подготовке не тестировалась. |
| Другие архитектуры / Python 3.14+ | Не проверены; требуется проверить наличие wheel зависимостей. |

Используйте версию ОС, поддерживаемую выбранным дистрибутивом Python.
Часть транзитивных зависимостей содержит нативные расширения. Если подходящий
wheel отсутствует, pip может потребовать компилятор/средства сборки для вашей
платформы. Сам SDK компиляции не требует.

## Что Установится Автоматически
Прямые зависимости исполнения из pyproject.toml:

| Пакет | Требуемая версия | Назначение |
| --- | --- | --- |
| web3 | >=7.13,<8 | EVM JSON-RPC, контракты и операции с ABI |
| eth-account | >=0.13.7,<0.14 | Локальные аккаунты, получение ключей из сид-фразы и подпись |
| aiohttp | >=3.12,<4 | Асинхронные HTTP- и WebSocket-клиенты |
| python-dotenv | >=1.0 | Поддержка необязательной локальной конфигурации dotenv |

pip также установит их транзитивные зависимости, например eth-abi, eth-utils,
eth-keys, hexbytes, rlp и pydantic. Точные версии и полный состав зависят от
версии Python, платформы и выбора pip. Это не фиксированный полный lock-файл.
Устанавливать каждую библиотеку вручную не нужно. `pip check` проверяет согласованность.

pytest, pytest-asyncio, Ruff, mypy, build и Twine ставятся только с `[dev]`.
Дополнительному скрипту сравнения upstream нужны парсеры tree-sitter;
они не входят в зависимости исполнения и не ставятся при обычной установке SDK.

## Установка И Проверка
```shell
python --version
python -m venv .venv
```
Активация в Windows PowerShell:
```powershell
.\.venv\Scripts\Activate.ps1
```
Активация в Linux/macOS:
```shell
. .venv/bin/activate
```
Затем установка прямо из версионного релиза GitHub:
```shell
python -m pip install --upgrade pip
python -m pip install "https://github.com/maxwell2010/decimal-web3-sdk/releases/download/v0.1.1/decimal_web3_sdk-0.1.1-py3-none-any.whl"
python -m pip check
python -c "import decimal_web3_sdk; print(decimal_web3_sdk.__version__)"
python -m pip list
```

Ожидаемая версия SDK: `0.1.1`. Для установки сид-фраза и приватный ключ не нужны.
Клиент и CLI по умолчанию используют **mainnet**. Для тестов явно выбирайте
`NetworkConfig.testnet()` либо `decimal-sdk --network testnet ...`.
В примерах отправка отключена; установка пакета сама не отправляет транзакции.
