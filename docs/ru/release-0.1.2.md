# Decimal Web3 SDK 0.1.2

Предварительный релиз GitHub серии 0.1. Python 3.10+, MIT, поддержка Windows/Linux.
[English notes](https://github.com/maxwell2010/decimal-web3-sdk/blob/v0.1.2/docs/en/release-0.1.2.md)

## Обновление 2026-09-16 Без Смены Версии
По запросу автора обновлены существующий тег v0.1.2, wheel и sdist; номер пакета
остается 0.1.2. Контрольные суммы изменились. Релиз остается предварительным.
- Исправлены вложенные повторы запросов и переключение контрактных чтений на резервный RPC.
- Исправлен результат комиссии: потолок цены type-2 не выдается за фактически списанную
  комиссию. Без надежной effectiveGasPrice сумма остается неизвестной, успех сохраняется.
- Добавлены 41 регрессионный тест по 7 сохраненным транзакциям и общий реестр проверок.
- Добавлены отдельные opt-in инструменты проверки кошелька без подписи и ограниченных
  бюджетом self-transfer тестов. Обычная установка ничего не отправляет в сеть.
- Тестовые JSON-эталоны входят в sdist, рабочие секреты и локальные отчеты исключены.

Если 0.1.2 уже установлен, обычный --upgrade может его пропустить. Обновите без кеша:
```shell
python -m pip install --force-reinstall --no-cache-dir "https://github.com/maxwell2010/decimal-web3-sdk/releases/download/v0.1.2/decimal_web3_sdk-0.1.2-py3-none-any.whl"
python -m pip check
```
Для воспроизводимости сохраняйте wheel вместе с его суммой из SHA256SUMS.

## Изменения
- Исправлена проверка HTTPS/WSS через certifi. Свой CA-файл можно настроить;
  проверка сертификата и имени домена не отключается этим исправлением.
- Добавлены 24 типизированных метода weighted Safe, NFT-стейкинга, валидаторов,
  токенов и стейкинга. Каталог содержит 79 высокоуровневых транзакционных методов.
- Сохранены точные суммы и неподписанный расчет комиссии до локальной подписи.
- Обновлены RU/EN документация, требования установки и сравнение официальных SDK.
- Добавлены постоянная команда обновления pip и проверка отсутствия длинных тире.

## Установка Или Обновление
Git и вход в GitHub не требуются:
```shell
python -m pip install --upgrade -r "https://raw.githubusercontent.com/maxwell2010/decimal-web3-sdk/main/requirements-latest.txt"
```
Команда выбирает последний опубликованный предварительный релиз. Обновление происходит
только при ее запуске. Указатель ведет на версионный wheel, не на изменения разработки.

Для новой установки этой версии:
```shell
python -m pip install "https://github.com/maxwell2010/decimal-web3-sdk/releases/download/v0.1.2/decimal_web3_sdk-0.1.2-py3-none-any.whl"
```

## Проверки И Ограничения
Локально проходят 329 офлайн-тестов. Линтер, генерация справочника,
проверка исходников/архивов на секреты и проверка wheel/sdist обязательны перед выпуском.
Подтверждены четыре отдельно согласованных mainnet self-transfer теста с общей
комиссией 0.159548649975 DEL; старые успешные операции учтены отдельно в реестре.
Для сборки и публикации новые подписи и отправки не выполнялись. Повторное чтение
testnet завершилось таймаутом; это не проверка всех endpoints. Полные lifecycle
NFT, Safe, управления валидаторами и ряда других операций не подтверждены в сети.
Три legacy-метода требуют opt-in; сохраняются partial-различия ABI/permit.
Это не stable, не полное совпадение с официальными SDK и не публикация в PyPI.
