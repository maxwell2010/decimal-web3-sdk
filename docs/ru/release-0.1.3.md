# Decimal Web3 SDK 0.1.3

Предварительный релиз GitHub для Python 3.10+. Обновлены адреса контрактов
тестовой сети и операции с токенами и NFT. Для двухшагового обновления токена
SDK теперь показывает обе комиссии и оба хеша. В тестнете подтверждены операции
с DEL, ERC20, запросы стейкинга, DRC721 и DRC1155.
При совместимом permit операция остается одной транзакцией. В остальных случаях
дополнительный approve требует явного согласия приложения.

Это не полный паритет с официальными SDK и не независимый аудит. Запрос на
отзыв стейка еще не означает возврат средств. [Результаты тестов](../validation/testnet-transaction-campaign-2026-09-24.ru.md)
и [ограничения](status.md).

Установка без Git:

```shell
python -m pip install --upgrade -r "https://raw.githubusercontent.com/maxwell2010/decimal-web3-sdk/main/requirements-latest.txt"
```
