Поля без значения по умолчанию обязательны. `*_wei` означает минимальные единицы
DEL, `*_raw` означает минимальные единицы токена; `amount_del`, `amount`,
`amount_in` задаются в обычных единицах. Один DEL равен 10^18 минимальных единиц.
Decimals токена берется из контракта. Повторно делить сумму после ребейса нельзя.

Для каждой транзакции приведен самостоятельный пример. Задайте используемые
в нем переменные окружения. Сид-фраза вводится скрыто локально; выбрана testnet,
отправка отключена. [Безопасность](../../SECURITY.md).
